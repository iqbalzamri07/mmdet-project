        How to label

        Follow these steps with your teammate. Split videos - don’t edit the same one at once.

        1. Set your name in the Videos panel (so locks and save history show who labeled).
        2. Pick a video from Need (or Done to review).
        3. Choose posture + activity (e.g. standing + smoking).
        4. Mark start / end on the timeline, then Draw crop tightly around one person.
        5. Save segment, repeat if needed, then Save all.

        Tip: click the same video again to deselect and leave editing. One person per crop — if someone walks into the box, shorten the segment or redraw.
